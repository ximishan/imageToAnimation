# ImageToAnimation 功能清单

## v0.1.0 已完成

### 素材
- [x] 最多 4 个图片目录
- [x] 3 图 / 4 图模式
- [x] 每目录各取 1 张
- [x] 多目录混合随机
- [x] 指定单个目录抽取
- [x] 同一成品内部不重复
- [x] 洗牌轮播，尽量让素材均匀使用
- [x] 当前批次避免完全相同的组合

### 拼接图片
- [x] 9:16（1080×1920）
- [x] 3:4（1080×1440）
- [x] 16:9（1920×1080）
- [x] 自定义宽高
- [x] 3/4 张图片独立高度比例
- [x] 等比例 cover 裁切，不拉伸
- [x] 拼接接缝虚化开关
- [x] 虚化范围与强度调节
- [x] 批量 JPG 输出
- [x] JPG 质量参数

### 图片转视频
- [x] 3 图 / 4 图
- [x] 每张图片随机显示 3–5 秒（范围可改）
- [x] FFmpeg H.264 MP4
- [x] 30 FPS 默认
- [x] 随机 `xfade` 转场
- [x] 淡化 / 左滑 / 右滑 / 上滑 / 下滑 / 溶解
- [x] 转场时长可调
- [x] 静音 AAC 音轨，提高平台兼容性
- [x] 批量 MP4 输出
- [x] H.264 CRF 可调

### 桌面工具
- [x] CustomTkinter GUI
- [x] 图片 / 视频输出模式切换
- [x] 素材组合预览
- [x] 输出进度
- [x] 生成日志
- [x] 自动记住上次目录与参数
- [x] `bin/ffmpeg.exe` 自动识别
- [x] FFmpeg 下载脚本
- [x] PyInstaller 打包配置
- [x] Windows GitHub Actions 自动构建
